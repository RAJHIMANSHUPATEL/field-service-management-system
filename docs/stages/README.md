# Stages

Each stage is one slice of the product that can be signed in to and used. The delivery phases in the [execution plan](../../README.md) stay the long-term sequence. A stage records what was actually decided and finished.

| Stage | Status | Record |
|---|---|---|
| 1 — Sign-in, request-ready master data, and the dashboard | Complete | [stage1.md](./stage1.md) |
| 2 — Request to work order | Complete | [stage2.md](./stage2.md) |
| 3 — Assign the work order | Complete | [stage3.md](./stage3.md) |
| 4 — Schedule the visit and accept the job | Complete | [stage4.md](./stage4.md) |
| 5 — Start the accepted job | Complete | [stage5.md](./stage5.md) |

The next stage starts when we pick it. Add `stage6.md` here when that work begins.
